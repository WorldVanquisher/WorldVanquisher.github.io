The model proposes existing Concepts and explains its choice; the user confirms each item before membership changes.     Result: on an isolated fixture with 1,543 reviewable units, the initial review response shrank from about 821 KB to 27 KB. The learner can return to a previous unit, find an old question and save a new one without manually constructing JSON.

  • Building explainable hybrid search with Go, SQLite and Qdrant

    I added an explicit hybrid search mode to French Learning Hub so a learner can find a Concept through both its wording and its meaning, then inspect how that result was retrieved. The implementation combines existing SQLite keyword results with Qdrant semantic results, exposes their evidence in React, and checks the final results against current records.

    My engineering contribution: defining a bounded ranking contract, integrating the two production search paths, making the result evidence visible, and driving acceptance through an independent ranking oracle.

  • When the response never arrives: idempotent annotation writes

    发布日期：2026-10-09

    Engineering focus: API idempotency, transactions and frontend recovery.

    Every decision in the Concept Review workbench is an HTTP POST. Usually the
    browser sends it, the server commits it, and the response comes back. The
    interesting case is when the response does not come back: the connection drops,
    the laptop sleeps, a proxy times out. Did the write happen?
