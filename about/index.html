French Learning Hub — from learning questions to searchable knowledge

July 2026–present · Project owner · Go, SQLite, React, TypeScript, Docker, Qdrant, AWS

Repository · Architecture · Development history · Case studies

I built French Learning Hub to turn questions scattered across French-learning conversations into a durable knowledge system. A learner can capture a question, review its interpretation, extract knowledge units, organize Concepts and search back to the original evidence. I own the product direction, architecture decisions, task definitions, review and deployment workflow; implementation uses Claude Code and Codex alongside that engineering process.

The core design keeps the learner’s words, model interpretations and human decisions separate. Versioned analyses and append-only feedback preserve history; current membership and derived support make it possible to correct a Concept without rewriting its evidence. The React workbench connects these backend rules to a practical review workflow.

Personal AI Workbench — portable context and reliable handoffs

October 2026–present · Project owner · Python, CLI, Markdown, TOML, GitHub Actions

Repository · v0.2.0 release

I built a Python CLI to solve a recurring development problem: project decisions and task state get scattered across notes and coding sessions. PAI assembles task-relevant context within a character budget and creates structured handoffs that preserve human constraints and separate implementation, validation, commit, merge and deployment status.

The engineering work extends beyond prompt assembly: concurrent writers cannot overwrite reports, discovery is bounded, launchers pin imports to the installed bundle, and release packaging excludes personal configuration and handoffs. A 10-job CI matrix covers Windows, macOS, Ubuntu and four Linux container userspaces, including extracted-bundle smoke checks.
